Smetanav0.1.0

An open-source desktop app for supervising autonomous coding agents: one window over a project's bd issue tracker, its worktree files and the agent sessions working in them. It notices when an agent is waiting on a person, including one in a tab nobody is looking at.

Source, issues and releases are on GitHub. Contributions are welcome.
